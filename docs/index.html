首次使用

安装一次，之后从扩展打开。

  1. 下载并完整解压

    Windows 使用支持 7z 的工具，例如 7-Zip；Mac 双击 ZIP 解压。将整个目录放到固定位置，不要直接在压缩包里运行。

  2. 连接本机组件

    Windows 双击 Install-Connector.cmd；Mac 双击 Install-Connector.command。只为当前用户注册本机连接。

  3. 加载浏览器扩展

    Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。打开“开发者模式”，选择“加载已解压的扩展程序”，选中解压目录里的 extension 文件夹。

  4. 登录自己的 ChatGPT

    固定扩展并打开侧栏，点击登录，在 OpenAI 官方页面完成。模型权限和用量取决于你的账号。

  5. 播放英语，共享标签页声音

    选择正在播放视频的标签页，并勾选“共享标签页音频”。结束时点“结束采集并保存”，等待译文完成后导出。

侧栏无法共享声音？

点击“完整页面”，或运行 Windows 的 Start.cmd / Mac 的 Start.command。翻译期间保持采集页面打开。

可选功能 · 默认关闭

先试听，再开始中文朗读。

  1. 采集前勾选中文朗读

    选择本机中文声音和语速，点击试听。没有中文声音时，可先安装系统中文语音；文字翻译仍可使用。

  2. 保持 YouTube 音量开启

    共享播放标签页的音频。中文朗读时屏蔽英文外放，读完或暂停后恢复，英文识别继续进行。

  3. 只读新的中文正文

    不读时间戳、核实说明或历史记录。积压过多会跳过较早的朗读，文字仍保留。朗读使用本机语音，不增加配音 API 或 Codex 请求。

中文需要等待识别与翻译，不是零延迟同传。不同浏览器和系统声音表现仍需公开测试。

测试前了解

本轮重点：中文声音与直播衔接。

Windows 包已做文件核对和本地识别检查。Mac 包分别在 Apple 芯片和 Intel 的原生环境中完成组件运行、合成英语识别、账号隔离和重新解压后的检查。新增朗读逻辑有 13 项自动检查，Windows 浏览器试听与音轨分离已检查；Mac 浏览器朗读、不同系统中文声音、音频共享及长时间真实直播仍需试用反馈。

译文有分段等待，数字和政策措辞可能存在识别错误。标记“待核实”的内容请结合原音判断。声音在本机识别，识别后的英文与相关上下文会发送给 OpenAI 翻译。
