隐私与数据处理

适用版本：0.2.2-beta · 更新日期：2026-09-29

本说明适用于 @PhyrexNi 发布的“美联储英语直播译文”浏览器扩展、本机连接组件，以及本项目的 GitHub 下载与说明页面。工具的用途是将用户主动选择的英语视频声音翻译为中文，并在用户电脑上保存、复制和导出译文。

选择什么，处理什么

用户在浏览器系统共享窗口主动选择播放标签页并共享音频。音频在本机暂存于内存并进行语音识别。本工具不持久保存原始音频或英语逐字稿，不读取 YouTube 账号、网页 Cookie 或浏览历史，也不向网页注入脚本。

哪些内容会发送给 OpenAI

为完成翻译，识别出的英语、必要的近期上下文及相关术语会通过官方 Codex 发送给 OpenAI。用户使用自己的、支持 Codex 的 ChatGPT 账号；账号权限、额度以及 OpenAI 的保留和处理规则适用该用户自己的账号设置与 OpenAI 政策。本工具的“不保存英文原文”是指本工具本地不持久保存，并不代表 OpenAI 不处理或保留请求内容。

工具不设发布者的云端翻译服务器，不向发布者上传音频或译文，不添加广告或使用分析追踪。

账号与本机记录

登录由官方 Codex 与 OpenAI 登录页面处理。扩展不接收密码、Cookie 或令牌。Codex 登录凭据保存在本机解压目录的 user-data/account；中文记录和自定义术语保存在 user-data。文件可被同一电脑上拥有相应权限的用户或程序读取。

用户可导出或备份中文记录。删除账号和记录前，请先结束采集并运行 Stop.cmd，再自行删除相应的 user-data 内容。运行 Uninstall-Connector.cmd 只移除本机连接注册，不会自动删除记录和登录凭据。

浏览器权限与本机连接

扩展申请侧栏和本机连接权限，用于显示翻译界面和启动本机组件。本机服务监听 127.0.0.1:8878；写入请求需要本机校验令牌，仅允许匹配的扩展嵌入页面。共享声音由浏览器另外向用户征求许可。

GitHub 下载、网页和反馈

安装包通过 GitHub Releases 提供，说明页由 GitHub Pages 托管。访问、下载、登录和提交反馈会受到 GitHub 隐私声明的约束。GitHub Pages 会为安全目的记录访问者 IP 地址。本项目网页不添加第三方分析脚本。

GitHub Issues 是公开反馈区。请不要在反馈中上传登录凭据、Cookie、API 密钥、整个 user-data 文件夹或私人音视频。用户自行提交的公开反馈可能被其他访问者查看。
