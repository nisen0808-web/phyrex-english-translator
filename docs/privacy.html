隐私与数据处理

适用版本：0.3.1-beta · 更新日期：2026-10-01

本说明适用于 @PhyrexNi 发布的“美联储英语直播译文”浏览器扩展、本机连接组件，以及本项目的 GitHub 下载与说明页面。工具的用途是将用户主动选择的英语视频声音翻译为中文，并在用户电脑上保存、复制和导出译文。

选择什么，处理什么

用户在浏览器系统共享窗口主动选择播放标签页并共享音频。音频在本机暂存于内存并进行语音识别。应用不持久保存原始音频，中文记录不包含英文逐字稿；官方 AI 组件可能写入临时会话缓存，本工具会在翻译结束及下次启动时清理自己的缓存目录。异常退出时缓存可能暂时保留，因此不承诺英文从不落盘。工具不读取 YouTube 账号、网页 Cookie 或浏览历史，也不向网页注入脚本。

哪些内容会发给 AI

识别出的英语、必要的近期上下文及相关术语，通过所选官方 Codex、Grok Build 或 Gemini CLI 发给 OpenAI、xAI 或 Google。用户登录自己的账号；权限、额度及服务端数据处理适用该服务的账号设置和政策。不会自动换用另一家 AI，也不读取电脑中已有的 API 密钥。

工具不设发布者的云端翻译服务器，不向发布者上传音频或译文，不添加广告或使用分析追踪。

可选中文朗读

中文朗读默认关闭，只使用浏览器标记为本机服务的中文语音，不调用额外的云端配音接口。朗读设置只在当前页面中生效；不保存配音音频，不向发布者发送译文。选择朗读后，工具在中文播放时关闭受控的英文外放通道，英文识别音轨继续采集。

可选显卡加速

Windows 用户可主动运行显卡安装器，在兼容性检查通过后下载固定版本的 NVIDIA 官方 Python 软件包，并核对 SHA-256。加速组件只安装到本工具目录，不修改系统驱动。音频仍在本机识别；该功能不增加音频或译文上传渠道。

账号与本机记录

登录由所选服务的官方组件和登录页面处理。扩展不接收密码、Cookie 或令牌。ChatGPT 登录凭据位于 user-data/account；Grok 与 Gemini 位于各自的 user-data/providers/grok 和 user-data/providers/gemini；中文记录和自定义术语保存在 user-data。文件可被同一电脑上拥有相应权限的用户或程序读取。

用户可导出或备份中文记录。删除账号和记录前，请先结束采集并运行 Windows 的 Stop.cmd 或 Mac 的 Stop.command，再自行删除相应的 user-data 内容。运行 Windows 的 Uninstall-Connector.cmd 或 Mac 的 Uninstall-Connector.command 只移除本机连接注册，不会自动删除记录和登录凭据。

浏览器权限与本机连接

扩展申请侧栏和本机连接权限，用于显示翻译界面和启动本机组件。本机服务监听 127.0.0.1:8878；写入请求需要本机校验令牌，仅允许匹配的扩展嵌入页面。共享声音由浏览器另外向用户征求许可。

GitHub 下载、网页和反馈

安装包通过 GitHub Releases 提供，说明页由 GitHub Pages 托管。访问、下载、登录和提交反馈会受到 GitHub 隐私声明的约束。GitHub Pages 会为安全目的记录访问者 IP 地址。本项目网页不添加第三方分析脚本。

GitHub Issues 是公开反馈区。请不要在反馈中上传登录凭据、Cookie、API 密钥、整个 user-data 文件夹或私人音视频。用户自行提交的公开反馈可能被其他访问者查看。
