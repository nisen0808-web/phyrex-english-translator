@PhyrexNi · 美联储英语直播译文 0.3.1 测试版
Windows 10/11 64 位 · Chrome / Edge

支持什么
默认翻译美联储及财经英语，也可选“通用英语”翻译英语直播、回放、访谈和课程。
仅支持英语输入、中文输出。每段译文可单独复制，复制图标不会带上“待核实”的说明。
支持 TXT、Word 和 SRT 导出。不是逐字零延迟同传；有分段、识别与翻译等待。
美联储 / 财经场景内置 556 条术语（含缩写和常见变体），覆盖货币政策、通胀、劳动力市场、经济增长、金融市场、流动性工具、银行信用及数据口径。
按本段和近期主题选取相关术语，不会在每段翻译中发送整本词库。可编辑最多 1000 条；完整分类与口径说明见“术语库说明.md”。

首次安装（浏览器扩展测试版）
1. 将整个压缩包解压到一个固定的文件夹，不要直接在压缩包里运行。
2. 双击 Install-Connector.cmd。它只为当前 Windows 用户注册 Chrome/Edge 的本机连接组件，一般不需要管理员权限。
3. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
4. 打开“开发者模式”，选择“加载已解压的扩展程序”，选中解压目录里的 extension 文件夹。
5. 把“PhyrexNi · 美联储英语直播译文”固定到浏览器工具栏，点击图标打开侧栏。
6. 选择 ChatGPT、Grok 或 Google Gemini，点击对应按钮，在官方页面登录自己的账号。

如果无法使用开发者模式，也可双击 Start.cmd，在完整浏览器页面中使用同样功能。
浏览器扩展与本机连接组件缺一不可。这不是“只装扩展、没有任何后台组件”的版本。
测试包尚未上架商店；不要向其他人索要密码、Cookie、API 密钥或令牌。

日常使用
1. 在同一个 Chrome/Edge 浏览器中打开 YouTube 等英语视频，开始播放。
2. 点击扩展图标，等本地语音识别准备完成。
3. 选择“美联储 / 财经”或“通用英语”，再选择翻译模式。
4. 点击“选择直播标签页，开始翻译”，在浏览器共享窗口里选播放页面，并勾选共享标签页音频。
5. 开始后设置区自动收起。“设置 / 记录”可再次展开；需要更大界面可点右上“完整页面”。
6. 翻译期间保持侧栏或完整页面打开。关闭正在采集的页面/侧栏会结束采集。
7. 结束时点“结束采集并保存”，等待完成后导出。不要在处理途中关闭本机组件。
8. 不再使用时可运行 Stop.cmd 关闭后台服务。

账号、额度和数据
每个人登录自己选择的 AI 账号。ChatGPT 需要 Codex 权限、Grok 需要 Build 权限，Gemini 使用 Google 登录；详见 AI选择说明.md。
本包没有发布者的账号、翻译历史或本机配置；也不会自动借用接收者已安装的其他 Codex 登录。
语音模型在本机运行，识别后的英文文字会发送给所选 AI 的官方服务进行翻译。
应用记录只保存中文译文；官方 AI 组件可能生成临时缓存，翻译结束及下次启动时清理。详见 PRIVACY.md。
记录保存在 user-data/records；ChatGPT 登录在 user-data/account，Grok/Gemini 登录在 user-data/providers。
使用后的整个目录已经含有你自己的凭据和记录，切勿直接转发。分享时请只转发原始 ZIP 文件。

中断与限制
短暂网络故障会自动重试，额度不足或登录失效会暂停处理。处理好后点击“继续处理”。
如果所选模型不可用，可先更换翻译模式再继续。已有中文会保留。
原音仅在内存中暂存：退出后台、重启电脑或长时间积压后，尚未完成的片段需要从视频重播。
直播暂停采集期间漏过的内容不会自动追回。
“待核实”是识别或译法的不确定提示。数字、口音、多人同时讲话仍需核对。
SRT 时间从本次采集开始计算，并非 YouTube 原视频时间轴。
仅支持英语；非英语、夹杂语言和歌曲不在保证范围内。

维护与卸载
保留解压目录的位置。若移动目录，需要重新运行 Install-Connector.cmd 并重新载入 extension。
Uninstall-Connector.cmd 只移除属于本目录的浏览器连接注册，不删除你的记录或凭据。
在浏览器扩展管理页移除本扩展即可停止扩展入口。
这个测试版没有自动更新功能。请使用原始分发来源提供的后续版本。
从旧版升级时，先结束翻译并运行旧目录的 Stop.cmd，再将新版完整解压到新目录。需要迁移记录、自己的登录或自定义术语时，把旧目录的 user-data 文件夹复制到新版目录。
在新版目录重新运行 Install-Connector.cmd，并在扩展管理页将旧扩展换成新版 extension 文件夹。
如果迁移了旧术语表，在页面展开术语库，点击“补充内置术语”再保存。已有同名词条的自定义译法会保留。

中文朗读
开始采集前，勾选“中文朗读 · 朗读时屏蔽英文”，选择本机中文声音并试听。保持 YouTube 音量开启、共享标签页音频；中文朗读时屏蔽英文外放，读完恢复。没有本机中文声音时，文字翻译仍可使用。详见“中文朗读说明.md”。
