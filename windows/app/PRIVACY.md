# 测试版的数据处理 · 0.3.4-beta

- 用户主动选择共享的英语视频标签页及音频；语音识别在本机进行。为翻译，识别出的英文、短上下文和相关术语发送给所选 AI 服务。
- ChatGPT、Grok、Gemini 分别通过各自官方本机组件连接 OpenAI、xAI 或 Google；Claude API 和 DeepSeek API 分别直接向 Anthropic 和 DeepSeek 官方 API 发送请求。各服务对数据和额度的处理适用用户自己的账号设置及服务条款。
- Claude API 需要用户主动在本机页面输入自己的 Anthropic Console API 密钥；密钥在当前本机组件进程中保留于内存，关闭进程后需重新输入，也可手动清除。请勿将密钥发送给发布者或其他人。实际翻译调用可能产生单独的 API 用量和费用。
- DeepSeek API 需要用户主动输入自己的 DeepSeek API 密钥；密钥暂存在本机运行进程的内存，请求时经本机匿名管道传递；可手动清除，切换 AI 或关闭组件后需重新输入。翻译请求可能产生单独的 API 用量和费用。
- 本工具不设发布者的云端翻译服务器，不向发布者上传音频或记录，不添加广告或分析追踪，也不自动切换其他 AI。
- 中文记录和自定义术语保存在 user-data。应用不持久保存原始音频和英文逐字稿；Grok/Gemini 官方组件可能写入临时会话缓存，工具在每次翻译结束及下次启动时清理自己的临时目录。异常退出可能暂时留下缓存，因此不承诺英语从不落盘。
- ChatGPT 凭据由官方组件保存于 user-data/account；Grok 与 Gemini 使用各自的 user-data/providers/grok 和 user-data/providers/gemini 目录。请勿分享使用后的目录。
- 扩展只申请侧栏和本机连接权限，不注入视频页面、不读取网页账号或 Cookie。本机服务仅监听 127.0.0.1:8878，校验请求来源及写入令牌。页面与本机组件通信时，用户输入的 Claude 或 DeepSeek API 密钥会经过本机连接；不会通过发布者服务器转发。
- 安装和卸载只管理当前系统用户的本机连接注册。卸载后已有账号和记录仍保留，用户可停止组件后自行备份或删除 user-data。
- 可选中文朗读使用浏览器标记为本机服务的中文声音，不调用额外云端配音，也不保存配音音频。

请分享 GitHub Releases 的原始干净压缩包。扩展仍为 GitHub 公开测试版，尚未上架 Chrome/Edge 商店；Mac 包尚未经过 Apple 公证。
