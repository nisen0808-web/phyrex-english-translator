# 0.3.1 加速更新说明

本次减少连接与页面等待，保留语音模型、专业词库、上下文及校验。

- ChatGPT 提前准备连接，生成中文后立即推送；预热不额外请求翻译。
- 只更新发生变化的段落；断线自动恢复，已有译文和手动滚动位置保留。
- 生成中的中文只预览；完成校验后才可复制、朗读及导出。
- 推荐使用默认“实时跟随 · 自动 4–8 秒”。分段秒数不等于总延迟。
- 仅 Windows x64 的兼容 NVIDIA 显卡可运行 Enable-GPU.cmd 启用本机识别加速。先停止组件，首次下载约 1.1 GB，需 4 GB 空间；不兼容不下载，失败可继续用 CPU。Mac 仍用 CPU。
- 中文朗读、每段复制和 TXT / Word / SRT 导出继续保留。

连接预热与逐字显示仅用于 ChatGPT；Grok/Gemini 使用原翻译通道，共用页面推送和本机识别优化。没有新增 API 单独计费模式。
网络和 AI 服务速度会波动，不承诺零延迟或固定总延迟。完整说明与校验文件见 GitHub 的 v0.3.1-beta 版本附件。
