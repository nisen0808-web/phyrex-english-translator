# 测试版的数据处理

本工具优先用于美联储及其他英语视频的中文翻译。

- 扩展只申请侧栏和本机连接权限；不注入 YouTube 页面，不读取网页账号或 Cookie。
- 声音由用户在浏览器系统共享窗口中主动选定；识别在本机进行，译文显示在本机页面中。
- 为完成翻译，识别出的英语、短上下文和所选术语会通过官方 Codex 发送给 OpenAI。账号、额度和服务端处理规则适用用户自己的 ChatGPT 设置。
- 本工具不设发布者的云端翻译服务器，不上传译文到发布者服务器，不添加分析或广告追踪。
- 中文记录和用户修改的术语保存在 `user-data` 中；本工具不持久保存原始音频或英语逐字稿。
- 登录由官方 Codex 处理，凭据保存在 `user-data/account`。扩展不接收密码、Cookie 或令牌。请勿分享使用后的目录。
- 本机服务仅监听 `127.0.0.1:8878`，需要本机请求校验，并仅允许对应的扩展嵌入页面。
- 安装脚本只在当前 Mac 用户的浏览器配置目录注册本扩展的本机连接；卸载脚本只移除与当前目录匹配的注册项。
- 用户可备份自己的中文记录。若要移除账号和记录，请先结束翻译、关闭组件，再自行管理 `user-data` 文件夹。

测试版尚未提交 Chrome/Edge 扩展商店，也未经 Apple 公证。可用功能见 `先读我-Mac.md`，运行检查结果随 GitHub 版本附件提供。
