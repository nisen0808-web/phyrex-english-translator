# 测试版的数据处理 · 0.3.1-beta

- 用户主动选择要共享的英语视频标签页及音频；语音识别在本机进行。
- 为完成翻译，识别出的英语、短上下文和相关术语，经所选的官方 Codex、Grok Build 或 Gemini CLI 发给 OpenAI、xAI 或 Google。服务端处理及额度遵循对应账号与服务的规则。
- 不设发布者的云端翻译服务器，不上传记录到发布者，不添加分析或广告追踪。不会自动改用另一家 AI。
- 中文记录和自定义术语保存在 user-data。应用不持久保存原始音频和英文逐字稿；Grok/Gemini 官方组件可能写入临时会话缓存。本工具在每次翻译结束及下次启动时清理自己的缓存目录。异常退出可能暂时留下缓存，因此不承诺英语从不落盘。
- 登录由官方组件处理。ChatGPT 凭据位于 user-data/account；Grok 与 Gemini 使用各自的 user-data/providers/grok 和 user-data/providers/gemini 目录。扩展不接收密码、Cookie 或令牌。请勿分享使用后的目录。
- 扩展只申请侧栏和本机连接权限，不注入视频页面、不读取网页账号或 Cookie。本机服务仅监听 127.0.0.1:8878，校验请求来源及写入令牌。
- 安装和卸载只管理当前系统用户的本机连接注册。卸载后账号和记录仍保留，用户可停止组件后自行备份或删除 user-data。
- 可选中文朗读仅使用浏览器标记为本机服务的中文声音；不调用额外云端配音、不保存配音音频。

请分享 GitHub Releases 的原始干净压缩包。扩展仍为 GitHub 公开测试版，尚未上架 Chrome/Edge 商店；Mac 包尚未经过 Apple 公证。
